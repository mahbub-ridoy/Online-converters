# FileForge

A polished static landing page for an online file tools suite.

## Included Tools

- Image Compressor
- PDF Tools App
- Background Remover / Image Cleanup
- Video Compressor / Converter
- QR Code Studio
- Resume Builder
- Screenshot Beautifier

## Run Locally

Because this project is plain HTML, CSS, and JavaScript, it can be opened directly in a browser or served with:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Publish

The project is GitHub Pages ready. Enable Pages from the repository settings using the `main` branch and root folder.
